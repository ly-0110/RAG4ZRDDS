## 1. 目标

指南 §6.3 要求回答中至少显示 `来源：{文件名}，第 X 页，第 Y 节`，禁止只显示"来源于知识库"。
本草案统一三端字段：**后端 /sources（D）→ 答案内引用标记（C）→ 来源卡片渲染（E）**。

## 2. 字段表（基于现有 SourceRef，无新增传输字段）

`/query` 的 `sources` 事件与 `/sources/{request_id}` 已下发的 SourceRef（api.md v0.4）：

| SourceRef 字段 | 类型 | 来源（A 的 metadata） | Citation 用途 |
|---|---|---|---|
| `node_id` | str | `chunk_id` | 唯一标识、去重、调试溯源 |
| `source_id` | str | `source_id` | 逻辑来源键（如 `user_manual`） |
| `source_name` | str | `source_file` | **展示用文件名**（"ZRDDS用户手册.pdf"） |
| `section` | str | `section_path` | **展示用节路径**（"PART 6 … / 第18章 简化接口 / 18.1 …"） |
| `page_print` | int | `printed_page_start` | **展示用印刷页**（用户对照纸质/阅读器所见） |
| `page_physical` | int | `physical_page_start` | 程序跳转/排障用（前端可选用于 PDF 定位） |
| `score` | float | 检索得分 | 排序展示（可选），不进入引用文案 |

第三周 HTML 源接入时，SourceRef 计划追加 `source_url`（metadata 已预留），用于可跳转引用；本周不动传输形状。

## 3. 展示约定（提议）

1. **来源卡片（E）**：`《{source_name}》第 {page_print} 页 · {section 末级节}`；
   `section` 全路径过长时仅显示末两级，悬停/展开显示全路径。
2. **答案内引用标记（C）**：建议 `[n]` 编号对应 `sources` 数组下标（1 基），
   前端据此把 `[n]` 渲染为可点击锚点，点击滚动/高亮对应来源卡片。
3. **双页码展示**：默认只显示印刷页；物理页以辅助文本（如"物理页 111"）或
   排障模式呈现，避免用户困惑（印刷页 = 物理页 − 6）。
4. **版本**：当前唯一来源版本 2.0 可省略；第三周多来源后按指南 §8.4 展示版本差异提示。
