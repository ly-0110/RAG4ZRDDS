# UI 现代化升级工作流

## 📋 任务概述

本次任务目标是全面升级现有前端 UI，使其外观更现代、更美观。主题配色采用饱和度较低的天蓝色、湖蓝色和深蓝色以及必要的灰度色。

## 🎨 设计要求

1. **主题配色**：采用低饱和度的天蓝色、湖蓝色、深蓝色，并辅以必要的灰度色
2. **现代感**：采用卡片式设计（Card-based UI）、足够的留白（Whitespace）和柔和的圆角（Soft Radius）
3. **一致性**：确保所有组件在视觉和交互上保持高度一致性

## ⚙️ 工作流

### 步骤 1: 分析现有组件

- 查看当前核心组件结构
- 识别需要改进的区域
- 记录现有样式问题

### 步骤 2: 定义设计系统

- 创建 CSS 变量（Design Tokens）
- 定义颜色、字体、间距规范
- 建立统一的卡片和按钮样式

### 步骤 3: 重构核心组件

- 从 CitationsCard.vue 开始应用新主题
- 更新 App.vue 的整体布局
- 优化 ChatInput.vue 的输入体验

### 步骤 4: 全局应用

- 将新的设计系统应用到整个问答流程
- 确保用户体验的连贯性
