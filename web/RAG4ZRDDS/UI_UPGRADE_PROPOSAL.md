# UI 升级方案建议（成员 E 第三周）

## 📋 背景

当前 CitationsCard 组件功能完整，但视觉表现和信息密度有待提升。本方案提出 5 个升级方向，按优先级排序。

---

## 🎯 方案一：视觉增强（高优先级）

### 目标
提升整体视觉质感，改善用户体验。

### 具体改进

1. **颜色优化**
   - 卡片背景色从纯白改为柔和的浅灰 `#fafafa`
   - 边框颜色使用更柔和的蓝色系 `#dbe7f3`
   - 文字颜色层次分明（标题深蓝、正文深灰、辅助浅灰）

2. **字体优化**
   - 标题使用加粗 `font-weight: 600`
   - 元数据使用较小字号 `12px`
   - 印刷页码使用 monospace 字体突出显示

3. **间距优化**
   - 卡片内边距增加至 `8px 12px`
   - 元素间距统一为 `4-8px`
   - 详情面板独立区域，避免拥挤

### 预期效果
```css
.source-card {
  background: #fafafa;
  border: 1px solid #dbe7f3;
  padding: 8px 12px;
  margin-bottom: 8px;
}
```

---

## 📊 方案二：信息密度提升（高优先级）

### 目标
在有限空间内展示更多信息，减少用户滚动。

### 具体改进

1. **折叠/展开机制**
   - 默认只显示元数据
   - "查看详情"按钮展开完整内容
   - 收起按钮隐藏详情面板

2. **标签页设计**
   - 将来源信息分为"基本信息"、"详细内容"两个标签页
   - 用户按需查看不同信息层次

3. **紧凑布局**
   - 元数据使用 flex-wrap 自动换行
   - 相关度分数使用小字号显示
   - ID 字段仅在需要时显示

### 预期效果
- 减少页面滚动次数
- 提升信息查找效率
- 保持界面整洁

---

## 📱 方案三：响应式适配（中优先级）

### 目标
确保在不同设备上都有良好的使用体验。

### 具体改进

1. **移动端优化**
   - 卡片宽度自适应屏幕
   - 详情面板在移动端可横向滑动
   - 按钮尺寸适合手指点击（最小 44px）

2. **断点设计**
   ```css
   @media (max-width: 768px) {
     .source-card {
       padding: 6px 10px;
       margin-bottom: 6px;
     }
   }
   ```

3. **触摸优化**
   - 悬停效果改为点击反馈
   - 滚动定位使用平滑动画

---

## ♿ 方案四：可访问性改进（中优先级）

### 目标
确保残障用户也能正常使用。

### 具体改进

1. **ARIA 属性**
   - 详情面板添加 `aria-expanded`
   - 按钮添加 `aria-label`
   - 焦点状态可见

2. **键盘导航**
   - Tab 键可切换卡片
   - Enter/Space 触发详情展开
   - Esc 关闭详情面板

3. **颜色对比度**
   - 确保 WCAG AA 标准（4.5:1）
   - 使用高对比度配色方案

---

## ✨ 方案五：动画效果（低优先级）

### 目标
提升交互流畅度和视觉反馈。

### 具体改进

1. **淡入动画**
   ```css
   @keyframes fadeIn {
     from { opacity: 0; transform: translateY(-5px); }
     to { opacity: 1; transform: translateY(0); }
   }
   ```

2. **悬停效果**
   - 阴影增强 `box-shadow`
   - 轻微上移 `transform: translateY(-1px)`
   - 过渡时间 0.2s

3. **加载状态**
   - 详情请求时显示 loading 图标
   - 错误状态显示友好提示
